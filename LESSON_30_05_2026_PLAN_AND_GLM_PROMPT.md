# Урок 30.05.2026 — план + промпт для GLM

## Главная рамка

Это не конспект для учителя.  
Это полноценный сайт-урок, который ученик должен пройти сам:

```text
зашёл на сайт → выбрал урок 30.05.2026 → прошёл блоки → решил практику → увидел объяснения → получил ДЗ → вышел с закреплённым навыком
```

## Тема урока

```text
Орфография без угадайки: №12, №11, №14 + короткая добивка №23–25
```

## Главная цель

Ученик должен перестать выбирать букву “по ощущению” и начать решать через механизм:

```text
форма слова → часть речи → правило → ответ
```

## Главная фраза урока

```text
Не спрашивай “какая буква?”. Сначала спроси: “что это за форма?”
```

## Что НЕ делать

```text
Не делать входной срез.
Не делать adaptive diagnostic.
Не делать отдельную диагностику перед уроком.
Не менять маршрут по результатам теста.
```

Причина: урок фиксированный. Если срез не меняет маршрут, он только тратит время.

# 5. Блок 1 — №12. Глаголы и причастия

## Название

```text
№12. Глаголы и причастия: буква зависит от формы
```

## Цель блока

Ученик должен научиться различать:

```text
личная форма глагола
действительное причастие настоящего времени
страдательное причастие настоящего времени
форма прошедшего времени
причастие прошедшего времени
повелительное наклонение
исключение / словарная мина
```

## Главная мысль

```text
№12 решается не по звучанию, а через производящий глагол.
```

## Алгоритм

```text
1. Определи, что перед тобой:
   личная форма глагола или причастие.

2. Если это настоящее / будущее время:
   решай через спряжение.

3. Если это действительное причастие настоящего времени:
   1 спряжение → -УЩ- / -ЮЩ-
   2 спряжение → -АЩ- / -ЯЩ-

4. Если это страдательное причастие настоящего времени:
   1 спряжение → -ЕМ- / -ОМ-
   2 спряжение → -ИМ-

5. Если это прошедшее время или причастие прошедшего времени:
   смотри инфинитив.

6. Если глагол на -ИТЬ и образуется страдательное причастие прошедшего времени:
   И часто меняется на -ЕНН-:
   построить → построенный
   подстрелить → подстреленный

7. Повелительное наклонение:
   суффикс -И- сохраняется независимо от спряжения.

8. Мины:
   движимый
   приемлемый
   незыблемый
   ненавидимый
   зависевший / зависимый
```

## Обязательные обучающие примеры

### Пример 1 — спряжение

```text
кол..шь

Колоть — 1 спряжение.
Значит: колешь.
```

### Пример 2 — действительное причастие настоящего времени

```text
бор..щийся

Бороться — 1 спряжение.
Действительное причастие настоящего времени от 1 спряжения: -ЮЩ-.
Ответ: борющийся.
```

### Пример 3 — страдательное причастие настоящего времени

```text
вид..мый

Видеть — 2 спряжение.
Страдательное причастие настоящего времени от 2 спряжения: -ИМ-.
Ответ: видимый.
```

### Пример 4 — прошедшее / инфинитив

```text
потрат..вший

Потратить.
Смотрим инфинитив: потратить.
Перед -вш- сохраняется гласная инфинитива.
Ответ: потративший.
```

## Практика

Минимум:

```text

```

```ts
{
  id: string
```

# 6. Блок 2 — №11. Суффиксы

## Название

```text
№11. Суффиксы: сначала часть речи
```

## Цель блока

Ученик должен перестать мешать в одну кучу:

```text
суффиксы прилагательных
суффиксы существительных
суффиксы глаголов
суффиксы наречий
слова-исключения
```

## Главная мысль

```text
В №11 одна и та же буква может быть результатом разных правил.
Сначала часть речи — потом суффикс.
```

## Алгоритм

```text
1. Определи часть речи.

2. Если это прилагательное:
   -ЕВ- / -ИВ-
   -ЧИВ- / -ЛИВ-
   -ИСТ-
   -ЧАТ-
   -ЕНЬК- / -ОНЬК-

3. Если это существительное:
   -ЕК- / -ИК-
   -ЕЦ- / -ИЦ-
   -ИНК- / -ЕНК-
   суффиксы после шипящих под ударением

4. Если это глагол:
   проверь форму 1 лица:
   -ую / -юю → -ОВА- / -ЕВА-
   -ываю / -иваю → -ЫВА- / -ИВА-

5. Если это наречие:
   из-, с-, до- → -А
   в-, на-, за- → -О

6. Если слово не выводится быстро:
   занести в личный список мин.
```

## Обязательные обучающие примеры

### Пример 1 — наречие

```text
издавн..

Из окна → издавна.
Приставка из- даёт суффикс -А.
Ответ: издавна.
```

### Пример 2 — наречие

```text
направ..

На окно → направо.
Приставка на- даёт суффикс -О.
Ответ: направо.
```

### Пример 3 — глагольный суффикс

```text
завед..вать

Я заведую.
Если в 1 лице -ую / -юю, пишется -ОВА- / -ЕВА-.
Ответ: заведовать.
```

### Пример 4 — глагольный суффикс

```text
наста..вать

Я настаиваю.
Если в 1 лице сохраняется -иваю-, пишется -ИВА-.
Ответ: настаивать.
```

### Пример 5 — прилагательное

```text
разборч..вый

Суффикс -ЧИВ- пишется с И.
Ответ: разборчивый.
```

## Практика

Минимум:

```text
8 заданий формата №11
```

Каждое задание должно иметь:

```ts
{
  id: string
  sourceId: string
  taskNumber: 11
  rows: string[]
  answer: string
  explanation: string
  mechanisms: Array<'adjective' | 'noun' | 'verb' | 'adverb' | 'trap'>
}
```

## UI практики

Для каждого задания:

```text
1. Показать 5 рядов.
2. Поле “Ответ”.
3. Селект “Что проверялось?”:
   - прилагательное
   - существительное
   - глагол
   - наречие
   - исключение / мина
4. Проверка.
5. Разбор каждого ряда.
```

## Завершение блока

Блок считается пройденным, если:

```text
ученик решил минимум 6 из 8 заданий
```

# 7. Блок 3 — №14. Слитно / раздельно / дефис

## Название

```text
№14. Слитно, раздельно, дефис: сначала часть речи
```

## Цель блока

Ученик должен научиться отличать:

```text
союз
наречие
производный предлог
местоимение с предлогом
частицу
дефисную модель
пол- / полу-
```

## Главная мысль

```text
№14 не про “как пишется”, а про “что это в предложении”.
```

## Алгоритм

```text
1. Определи, что перед тобой:
   союз, наречие, предлог, местоимение, частица или дефисная модель.

2. Союз:
   можно заменить другим союзом.
   тоже = также = и
   зато = но
   чтобы = для того чтобы
   поскольку = так как

3. Местоимение / наречие с частицей:
   можно задать вопрос или вставить слово.
   то же самое
   так же, как...
   за то дело
   по тому пути

4. Производный предлог:
   часто имеет управление:
   в течение дня
   в продолжение недели
   вследствие ошибки
   на протяжении месяца

5. Наречие:
   отвечает на вопрос где? куда? когда? почему? как? в какой степени?
   часто пишется слитно:
   затем
   оттого
   отсюда
   вообще
   вполсилы
   настолько

6. Дефис:
   по-русски
   кое-где
   всё-таки
   какие-то
   во-первых

7. Пол-:
   через дефис перед:
   гласной
   Л
   заглавной буквой

   слитно:
   полпути
   полкомнаты

   полу- всегда слитно.
```

## Обязательные обучающие примеры

### Пример 1 — союз vs местоимение

```text
Мне стало стыдно за свои слова, а также за то, что я не оправдал надежд.

также — союз, можно заменить на “и”.
за то — местоимение с предлогом: стыдно за что?
```

### Пример 2 — так же

```text
Отчего люди не летают так же, как птицы?

так же — раздельно, потому что есть сравнение “как птицы”.
```

### Пример 3 — производный предлог

```text
На протяжении всей недели Сергей готовился к экзамену.

на протяжении — производный предлог, пишется раздельно.
```

### Пример 4 — дефис

```text
по-русски
кое-где
всё-таки
какие-то
```

## Практика

Минимум:

```text

```

В практике должны быть все типы:

```text

```

Каждое задание должно иметь:

```ts
  answer: string
  explanation: string

}
```

## UI практики

Для каждого задания:

```text
1. Показать условие.
2. Показать варианты.
3. Поле “Ответ”.
4. Селект “Что решало написание?”:
   - союз
   - наречие
   - предлог
   - местоимение с предлогом
   - частица
   - дефисная модель
   - пол-/полу-

```

# 8. Блок 4 — №23–25. Короткая добивка

## Название

```text
№23–25. Макротекст: контроль без раздувания
```

## Цель

Проверить, что ученик сохраняет навык по макротексту, но не превращать это в центр урока.

## Формат

```text
1 макротекст
3 задания:
№23 — содержание текста
№24 — типы речи / логико-смысловые отношения
№25 — лексика / фразеологизм / антонимы / синонимы
```

## UI

```text
1. Показать текст в удобной прокручиваемой области.
2. Показать задания 23–25.
3. Ответы вводятся отдельно.
4. После проверки показать:
   - правильный ответ;
   - где в тексте доказательство;
   - тип ошибки, если ответ неверный.
```

## Ограничение

Не писать новую теорию по 23–25, только короткие напоминания:

```text
№23 — сверяй с текстом, не с памятью.
№24 — проверяй тип речи и логическую связь по конкретным предложениям.
№25 — выписывай ровно то слово/сочетание, которое просит задание.
```
