# DemidHelp

Focused EGE prep web app built around lesson blocks and fast recall cards.

DemidHelp is a compact study tool for organizing preparation materials and repeated practice tasks in one place.

## Core idea

The project is built around two simple blocks:

- **Lesson blocks** — structured materials for the remaining preparation path.
- **Fast recall cards** — short EGE-style prompts for repetition and quick practice.

## Why it exists

DemidHelp was made for a real study workflow: reduce chaos, keep lessons visible, and turn repeated exam tasks into fast practice.

It is intentionally smaller than a full learning platform. The goal is focused preparation, not a generic edtech product.

## Features

- lesson-oriented structure
- quick recall practice
- focused EGE preparation flow
- clean web interface
- lightweight product scope

## Stack

- TypeScript
- Next.js
- React
- Tailwind CSS
- Radix/shadcn-style UI components
- Zustand

## Run locally

```bash
bun install
bun run dev
```

or with npm:

```bash
npm install
npm run dev
```
